# 我的主張

在營業秘密侵害案件中，證據保全的時機遠比證據內容本身重要。本案的關鍵轉折發生在我們聲請證據保全並取得被告個人電腦的數位鑑識結果後——即使鑑識結果只找到間接證據，但證據保全行動本身就改變了雙方的和解談判態勢。

# 實務經驗

- 民事證據保全（智慧財產案件審理法第 18 條）搭配刑事告訴（營業秘密法第 13 條之 1）的雙軌策略，在實務上對被告形成更大壓力
- 數位鑑識的價值不只在找到「機密檔案被複製」的證據——即使檔案已刪除，USN Journal 和 $LogFile 中的時間軸資訊也能證明異常存取行為
- 法院對證據保全的准駁門檻比一般認知低：若能提出「合理懷疑」，不需要達到「優勢證據」程度即可獲准

# 未解決問題

- 境外雲端儲存（如 Google Drive、Dropbox）的證據保全如何執行？目前實務上仍缺乏有效機制
- 員工使用個人裝置（BYOD）存取公司系統時，證據保全的範圍應如何界定？
- 「合理保密措施」的舉證責任分配在實務上仍有灰色地帶——雇主需證明到什麼程度，才轉由被告負舉證責任？

# 與外部觀點的比較

與最高法院見解一致：實務上確實不需要「滴水不漏」的資安措施。但我的經驗是，法官在審理時仍會不自覺地對「有完整資安政策」的原告產生較高可信度——制度的存在本身就具有說服力，即使制度的技術細節不完美。

與學說上的爭議對照：有學者認為台灣法院對「合理保密措施」的認定過於寬鬆，傾向保護雇主。但我個人的實務經驗是，在真正進入審理後，法官對「合理」的判斷其實相當務實——他們關注的是「雇主是否真的在乎這個秘密」，而非「資安措施是否完美」。
