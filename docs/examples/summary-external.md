# 核心結論

最高法院維持二審見解，認定原告公司對系爭技術資訊已採取「合理保密措施」，被告離職員工構成營業秘密法第 13 條之 1 之侵害。法院強調「合理保密措施」不以絕對不可破解為必要，重點在於雇主是否展現保護意圖並採取相應作為。

> **來源**：[最高法院 113 年度台上字第 XXXX 號判決](%60source%60)

# 關鍵論據

- 原告公司對系爭技術文件設有分級存取權限（三級：一般/機密/極機密），被告僅有「一般」等級權限
- 被告於離職前三個月內大量下載超出其職務範圍的技術文件，時間點與其轉職競業公司重疊
- 法院引用營業秘密法第 2 條，重申「合理保密措施」的判斷標準：客觀上足以使第三人知悉雇主有保密意圖，主觀上員工確實知悉其保密義務
- 被告抗辯「公司未使用 DRM 或禁止 USB 存取」被駁回——法院認為保密措施不要求「滴水不漏」

# 疑點與未解問題

- 法院對「合理保密措施」的判斷是否過度傾向雇主？中小企業若無完整資安制度，是否還能主張營業秘密保護？
- 判決未討論被告下載的技術文件中，有多少屬於「一般知識與技能」而應排除保護
- 離職前大量下載的「時間點」在本案中具有關鍵證據力，但若員工分批、小量下載，是否仍能建立因果關係？

# 關鍵術語

- **合理保密措施（Reasonable Secrecy Measures）**：[概念條目](../concepts/合理保密措施.md) — 營業秘密法第 2 條要件之一
- **營業秘密三要件**：秘密性、經濟價值、合理保密措施
- **競業禁止（Non-Compete）**：雇主與勞工約定勞工離職後不得從事與原雇主競爭之工作，需符合勞基法第 9 條之 1 的四項要件

# 對實務的影響

- 企業應建立文件分級存取制度，即便沒有高科技的 DRM 方案，權限分級本身就是有力的「合理保密措施」證據
- 離職審查應比對員工離職前 3-6 個月的檔案存取記錄，建立異常行為的時間關聯性
- 勞動契約中的保密條款與員工手冊中的資訊安全政策，應明確且定期更新，作為員工「知悉保密義務」的書面紀錄
